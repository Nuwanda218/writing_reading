# 从真空管到晶体管：开关的两次革命

> 变更日志：
> - v1.0 | 2026-10-08 16:24:48 | 初版：零基础讲透真空管（热电子发射、栅极控制）与晶体管（掺杂、PN 结、BJT、MOSFET）的物理机制

《计算机硬件》讲到硬件历史时，说真空管和晶体管都是"开关"。但"开关"这个词太轻巧了——它没告诉你：**一根玻璃管里到底发生了什么？一小块硅凭什么能当开关？**

这篇就补上这个缺口。我们只干一件事：**把这两种元件拆开，看清它们究竟是怎么"用电控制电"的。**

## 一、先搞清"开关"到底要什么

### 1.1 计算机的一切，都是电流的通和断

回忆《计算机科学》：0 和 1 能表达一切，靠的是香农 1937 年的证明——**开关电路和布尔逻辑是同一回事**。所以计算机的底层动作极其单调：**让电流通，或者断。**

那么问题来了：**谁来控制通断？**

### 1.2 两端器件当不了开关

拿一个灯泡举例。灯泡有两个接线端，你给它通电它就亮。但灯泡只能**被**控制——它没法去控制别的电路。**要"用电控制电"，器件必须有三只脚**：

- 一脚进（输入信号，很小）；
- 另两脚之间是主电流通路（很大）；
- 输入的小信号，决定主通路通不通。

**这就是"三端器件"。真空管和晶体管，本质上都是三端开关。**

### 1.3 放大和开关，是同一件事

你可能听过"真空管能放大信号"，觉得放大和开关是两回事。其实是一回事：**只要一个小信号能控制大电流，那么"连续地控制"就是放大，"一把控制到两头"就是开关。** 就像水龙头：慢慢拧是调水流（放大），一把拧到底或关死就是开关。

## 二、真空管：用烧红的金属发射电子

### 2.1 第一步：让金属"吐"出电子

金属里有大量自由电子。平时它们被束缚在金属内部，跑不出来。但**如果金属被加热到几百度，一些电子获得的能量足够大，就能挣脱表面飞出去**——这叫**热电子发射（Thermionic Emission）**。

1883 年，爱迪生研究灯泡时偶然发现：烧热的灯丝附近，如果有块金属板，板上会出现电流。他记下了这个现象（爱迪生效应），但没深究。

### 2.2 二极管：只会单向导电

1904 年，弗莱明把这个现象做成了元件：**真空二极管**。

- 一个抽成真空的玻璃泡（真空是为了让电子飞过去时不撞到空气分子）；
- 里面一根**灯丝**烧热**阴极（Cathode）**，阴极不停发射电子；
- 对面一块**阳极（Anode，也叫板极）**。

**阳极加正电压**：正电压吸引带负电的电子，电子从阴极飞向阳极，**电流通了**。
**阳极加负电压**：电子被推回去，**电流断了**。

**所以它只允许电流从一个方向走——这就是"单向导电"。** 但注意：它只能整流，还不能当开关用，因为**没有第三个端子来"控制"它**。

### 2.3 三极管：插进一张金属网

1906 年，德福雷斯特在阴极和阳极之间插了一张金属网，叫**栅极（Grid）**。真空三极管诞生了——**人类第一个能放大的器件。**

它的机制是这样的：

- 阴极发射电子，往阳极飞；
- 栅极在中间，如果给它加**负电压**，它就会**排斥**飞过来的电子，相当于在电子流上设了一道"闸门"；
- **栅极电压只要变化一点点，飞到阳极的电子数量就大幅变化** → 阳极电流大幅变化。

**这就是放大：小电压控制大电流。**

**怎么当开关？** 把栅极电压压到足够负，电子全被挡回去，阳极电流归零——**断（0）**；把栅极电压放开，电子畅通——**通（1）**。

### 2.4 为什么真空管注定被淘汰

- **费电、发热**：灯丝必须一直烧着，哪怕电路不干活；
- **寿命短**：灯丝会烧断，ENIAC 平均每两天烧一根；
- **又大又脆**：玻璃泡，一个就有手指粗；
- **慢**：电子在真空里飞，距离长。

ENIAC 用了 17,468 根真空管，重 30 吨，占一屋子。**它不是在算题，就是在修机器。**

## 三、晶体管：用半导体做开关

真空管的死穴是"要烧灯丝"。那能不能找一种材料，**不用加热、纯靠电就能控制导电**？答案藏在半导体里。

### 3.1 先搞懂：半导体是什么

按导电能力，材料分三类：

- **导体**：铜、银，电子随便跑，导电好；
- **绝缘体**：玻璃、橡胶，电子被锁死，不导电；
- **半导体**：硅、锗，**导电能力介于两者之间**——而且关键在"而且"：**它的导电能力可以被"调"。**

纯净的硅其实几乎不导电（电子都被共价键锁住了）。但**掺入极少量的杂质（掺杂，Doping）**，情况就完全变了：

- 掺**磷**：磷原子多一个电子，这个电子很自由 → **N 型半导体**（N = Negative，多自由电子）；
- 掺**硼**：硼原子少一个电子，留下一个"空位"（叫**空穴**，可以理解成能移动的正电荷）→ **P 型半导体**（P = Positive，多空穴）。

**掺杂的浓度极低（百万分之一量级），却能让硅的导电能力变好几个数量级。** 这就是半导体的魔法：**导电能力可调。**

### 3.2 PN 结：单向导电的机关

把一块 N 型和一块 P 型贴在一起，交界处会发生什么？

N 型那边的自由电子会往 P 型扩散，P 型那边的空穴往 N 型扩散，两边一中和，交界处就空出一层没有可移动电荷的区域，叫**耗尽层（Depletion Region）**。这层耗尽层像一道墙，挡住了继续扩散。

结果：**电流只能从 P 流向 N（正向），反过来（N 到 P）被耗尽层挡住。** 这就是**PN 结**——半导体二极管的原理。

**记住这个"结"：晶体管的核心机关，就是两个 PN 结的巧妙组合。**

### 3.3 双极型晶体管（BJT）：1947 年的第一只晶体管

1947 年 12 月，贝尔实验室的巴丁和布拉顿做出了世界上第一个晶体管（点接触型），随后肖克利发明了更实用的**结型晶体管**。三人因此拿了 1956 年诺贝尔物理学奖。

它的结构是一个 **N-P-N 三明治**：

- 两头是 N 型，分别叫**发射极（Emitter）**和**集电极（Collector）**；
- 中间夹一层很薄的 P 型，叫**基极（Base）**。

**工作机制（直觉版）**：发射极发射电子，本来要往集电极去，但中间的基极像一道闸门。**基极只要通一点点小电流，就能让大量电子冲过基极到达集电极。** 于是：

**基极的小电流，控制集电极的大电流。**

这和真空管栅极干的是同一件事，只是把"真空里飞电子"换成了"半导体里跑电子"。它叫**双极型晶体管（Bipolar Junction Transistor，简称 BJT）**——"双极"是因为电子和空穴都参与导电。

### 3.4 场效应晶体管（MOSFET）：今天的主流

BJT 有个缺点：**基极要一直有电流**，费电。1959 年，贝尔实验室的 Kahng 和 Atalla 发明了另一种结构——**金属-氧化物-半导体场效应晶体管（Metal-Oxide-Semiconductor Field-Effect Transistor，简称 MOSFET）**，今天芯片里几百亿个开关几乎全是它。

它的结构是"三明治 + 一个隔空控制的栅极"：

- 一块硅衬底上做两个 N 型区，分别叫**源极（Source）**和**漏极（Drain）**；
- 中间隔着一段 P 型沟道；
- 沟道上方盖一层**绝缘的氧化物**，再上面是**栅极（Gate）**。

**工作机制**：栅极和沟道之间隔着绝缘层，所以**栅极不通电流**。但栅极加正电压时，会**通过电场**把电子吸引到沟道表面，形成一条导电通道（沟道），源极和漏极就通了；栅极电压撤掉，通道消失，就断了。

**关键差别：MOSFET 是"电压控制"，栅极几乎不耗电。** 这就是它比 BJT 省电、能做成几百亿个的原因。

### 3.5 晶体管为什么赢

| | 真空管 | 晶体管 |
|---|---|---|
| 开关原理 | 热电子发射 + 栅极 | 半导体掺杂 + 电场/电流控制 |
| 要不要加热 | 要（灯丝） | 不要 |
| 功耗 | 高（灯丝常烧） | 低 |
| 寿命 | 短（灯丝烧断） | 近乎无限 |
| 体积 | 手指粗的玻璃泡 | 纳米级 |
| 能不能集成 | 不能 | **能——整片印在硅片上** |

最后一行是胜负手：**晶体管能用光刻"印"在硅片上**，于是有了集成电路（1958），有了摩尔定律（1965），有了今天的几百亿晶体管。

## 四、从开关到逻辑门（下一站）

现在你手里有了一个"电控开关"（MOSFET）。但一个开关只能表示 0 或 1，还不会算数。**怎么让它算数？**

答案是**组合**。举个最小的例子：把两个 MOSFET 按互补方式接起来——上面一个 P 型、下面一个 N 型，输入接同一个信号：

- 输入高电平：下面 N 型导通、上面 P 型断开 → 输出接地 = **低电平**；
- 输入低电平：上面 P 型导通、下面 N 型断开 → 输出接电源 = **高电平**。

**输入高它输出低，输入低它输出高——这就是"非门"，一个会做逻辑判断的电路。** 这种互补结构叫 **CMOS（Complementary MOS，互补金属氧化物半导体）**。

把非门、与门、或门组合起来，就能搭出加法器；加法器加上存储，就是 CPU。**从一粒开关到一台会算数的机器，这条路就是这么铺出来的。**

## 五、小结 + 下一片叶子

**真空管和晶体管，本质都是"三端开关"：用一个小信号控制一条大电流的通断。** 真空管靠"烧红的金属发射电子 + 栅极拦截"，晶体管靠"半导体掺杂 + 电场控制沟道"。前者要烧灯丝，注定又大又费电；后者不用加热、能做得极小、还能整片印在硅片上——**所以晶体管赢了，计算机才从一屋子变成了一口袋。**

**下次你看到"几纳米制程""几百亿晶体管"的新闻，就知道那是在说：人类把这种"电控开关"，又印小了一点。**

开关会做了，但一个开关还不会算数。**下一片叶子，我们去看：怎么把开关拼成逻辑门，再用逻辑门拼出会做加减法的电路。**
