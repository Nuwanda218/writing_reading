# RNN 与 LSTM：让机器"记住"的循环网络

> 变更日志：
> - v1.0 | 2026-08-22 11:08:54 | 初版：循环网络怎么读完整句、LSTM 怎么治"记不住"、回到输入法

《大语言模型》演化史第四步，我们只用一小段讲了 RNN 和 LSTM。但这段历史埋着 NLP 最迷人的一个转折：**机器第一次学会了"记忆"。** 而且它离你不远——你天天用的输入法联想，就是这类模型（或它们的后辈）在干活。这篇把它拆开，从"为什么需要记忆"讲到"LSTM 怎么治记不住"，最后回到你的输入法。

## 一、问题：读长句，光"看"不够，还得"记"

先回到一个具体的场景。你要让机器判断这句话的情绪：

> 虽然我已经喝了三杯咖啡，而且刚才还吃了一块非常甜的蛋糕，但是我现在……还是觉得困。

正常人读到结尾"困"，还记得开头是"喝了咖啡"——但传统方法记不住。为什么？

- **n-gram**（《大语言模型》第一步）：只看前面几个词，看到"觉得"，它根本不知道 20 个字前有"咖啡"。
- **词向量**（word2vec）：每个词只有自己的向量，词与词之间的先后、远近，它完全不管。

**问题来了：让机器"读完整句话"，它需要一个东西——对前面内容的"记忆"。** 比如一个"到目前为止讲了什么"的浓缩，读到结尾时还能带着开头的信息。RNN 就是为这个而生的。

## 二、RNN：一个会循环的"记忆"

**RNN（Recurrent Neural Network，循环神经网络）** 的核心设计，一句话：**一个会"记住"的网络，一个词一个词地读，每读一个词就更新一次记忆。**

它多了一样 n-gram 和词向量都没有的东西——一个**隐藏状态（Hidden State，简称 h）**，相当于"到目前为止，这句话在我脑中的浓缩记忆"。处理流程是这样：

```
读到词 → 把"这个词"和"上一步的记忆 h"合并 → 更新出新的 h → 顺便预测下一个词
```

走一遍"今天 天气 很"这句话：

```
① 读"今天"  → 记忆h₁ = 浓缩"今天"  → 预测下一个词可能是"天气/是/的"
② 读"天气"  → 结合h₁，更新h₂ = 浓缩"今天天气" → 预测下一个词可能是"很/不错/真好"
③ 读"很"    → 结合h₂，更新h₃ = 浓缩"今天天气很" → 预测下一个词可能是"好/不错/冷"
```

看出来了吗？**每读一个新词，它都要回头看"我上一步记着什么"，两者合并成新记忆。** 这就是"循环"二字的由来——同一个网络，被反复用于每一个时间步，像把同一个"记忆器官"放在每一句话的每个词上。数学上它做的事极简：**h新 = 激活(权重 × 当前词 + 权重 × h旧)**——还是《神经网络基础》的"加权求和 + 过闸门"，只是多了"把上一步的记忆也当输入"。

它像什么？像你读句子时在纸上写摘要：每读一句，把"到这儿为止讲的是什么"重写一遍，最后纸上的摘要就是整个句子的浓缩。**RNN 让机器第一次能"读完整句"——结尾的判断可以带着开头的信息。**

## 三、死穴：它其实"只记得最近几个词"

但 RNN 有个致命伤，你读《ReLU激活函数》时已经见过它的凶手——**梯度消失**。在这里，它换了个更狠的形式。

回忆：RNN 的记忆要跨很多个词传递（"咖啡"在第 3 个词，要到第 30 个词才用上）。而训练时，反向传播要**一步一步往前传**（第 30 步 → 第 29 步 → …… → 第 3 步），每跨一步都要乘一个小于 1 的数（激活函数的导数，最多 0.25）。跨 27 步，就是 0.25 的 27 次方——**比零还小，第 3 步那个词根本收不到训练信号，它的记忆就没人去调。**

结果就是那句扎心的话：**RNN 看着读完了全句，其实只记得最近几个词。** 长句一长，开头的东西早就在它脑中被"乘没"了。说好的"读完整句"，长句还是记不住。

## 四、LSTM：给记忆装三扇门

1997 年，有人发明了 **LSTM（Long Short-Term Memory，长短期记忆网络）**，专门治"记不住"。它的思路，是把 RNN 那一个"记忆"拆成两样东西：

- **细胞状态（Cell State，简称 C）**：一条"长途记忆"的直通高速公路——信息能在这条路上**原样走很远，不衰减**。这是 LSTM 的灵魂。
- **隐藏状态 h**：短途的、要拿出来用的记忆。

关键是：这条"高速公路"不是随便让人走，它装了**三扇门**，由当前输入和旧记忆共同决定开多少：

1. **遗忘门（Forget Gate）**：决定旧记忆**忘掉多少**。看到"但是"，知道转折要来了，就忘掉一部分旧重点。
2. **输入门（Input Gate）**：决定当前的新信息**记住多少**。看到"咖啡"，觉得重要，就写进长途记忆。
3. **输出门（Output Gate）**：决定从长途记忆里**拿出多少**用于当前输出和预测。

每读一个词：**先决定忘什么 → 再决定记什么 → 更新长途记忆 → 再决定说什么。** 三扇门全都是"可学习的旋钮"（还是《神经网络基础》那套），训练时它们自己学会"什么该记住、什么该忘掉"。

类比：像你处理一句长话时的笔记法——**遗忘门 = 划掉不重要的旧笔记；输入门 = 写下新的重点；输出门 = 现在该把哪条读出来用。** 因为新重点走的是"直通高速公路"（不用每步乘衰减的数），**咖啡在第 3 个词记住，到第 30 个词还能用上**——这就是 LSTM 治"记不住"的原理。它在 2014 年前后成为 NLP 的主力，统治了机器翻译、语音识别很多年。

## 五、它的亲戚们（点到为止）

两个名字你知道存在即可：
- **GRU（Gated Recurrent Unit，门控循环单元）**：LSTM 的简化版——三扇门砍成两扇，参数更少、更快，效果接近。现在实际工程里 GRU 用得往往更多。
- **双向 RNN（Bidirectional RNN）**：正着读一遍、反着再读一遍——这样每个词不仅知道"前面的"，还知道"后面的"。增强版，代价是算两遍。

## 六、回到输入法：你手机里的"预测下一个词"

现在回答你最初的好奇。你在输入法里打"今天天气"，它联想"很好/不错/怎么样"——**这本质上就是一个"语言模型在预测下一个词"**（《大语言模型》第一步那件事），只是它得在毫秒级、在手机的小内存里完成。

输入法联想用的语言模型，有两种世代的引擎：
- **老式：n-gram 数数**——统计"天气"后面常跟什么词，直接查表。简单，但记不住长距离、生僻组合会瞎。
- **新式：神经网络语言模型**——RNN/LSTM 一度是主流选择（它们擅长"记忆"，输入法正好要预测"下一个词"），后来也换成更小的 Transformer 变体。神经网络版的好处是能泛化：你打过"今天天气真不错"和"今天心情真不错"，它学到"真不错"可以跟很多词，下次就能联想出来。

这里有个关键差异值得记住：**ChatGPT 是大语言模型，输入法是小语言模型——它们做的是同一件事（预测下一个词），差别只在规模、速度、和它跑在谁的内存里。** 你手机里那个几百 MB 的输入法，塞不进几千亿参数的 GPT，所以它用小巧的模型，只干"联想下一个词"这一件事，做到快和准。

## 七、退场：为什么被 Transformer 取代

你可能会问：LSTM 这么好，现在怎么没人提了？答案你在《Transformer》学过了——**串行**。

LSTM 必须一个词一个词顺序读（第 3 个词必须等第 1、2 个处理完），没法并行，训练慢得堆不起大模型；而 Transformer 让所有词同时互相看（并行），还顺带解决了长距离依赖（注意力全连接，不用靠"记忆传递"）。**LSTM 治好了"记不住"，但没治好"串行慢"——Transformer 把它连病根一起解决了。**

但"记忆"这个思想没有死：**LSTM 和它的后辈仍然是语音识别、时序数据（股价、传感器）、以及一些轻量设备上的主力**——凡是"一串有顺序的数据、需要记住前面"的场景，循环网络依然在岗。它只是退出了"语言模型"这个它曾统治的舞台。

**总结判断**：RNN 和 LSTM 是机器第一次学会"记忆"的里程碑——RNN 引入"隐藏状态"（边读边更新记忆），LSTM 用"三扇门 + 长途高速路"治好了"记不住"（梯度消失）。它的一生浓缩了一个规律：**每一代模型都在治上一代的病，而它的病又成了下一代的机会**——LSTM 治好了 RNN 的"记不住"，Transformer 治好了 LSTM 的"串行慢"。你在输入法里享受的每一次联想，都是这场接力留下的遗产。
