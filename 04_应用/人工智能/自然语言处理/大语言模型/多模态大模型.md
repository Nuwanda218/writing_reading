到目前为止，你学的都是"文本进、文本出"。但 2024 年后的顶级大模型早就不是了——**你发一张照片，它能描述；你发一段语音，它能听懂**。这篇讲多模态大模型（Multimodal LLM）：怎么让一个 Transformer 同时看懂文字、图像、声音，以及它为什么能"什么都吃"。

## 一、核心思想：一切都是 token

先回到最底层的一句话，它贯穿你学的所有内容：**计算机只认数字，Transformer 只处理一串 token**（《Transformer》第 1 步）。文本为什么能进 Transformer？因为每个词被切成了 token、变成了数字向量。

多模态的野心就一句话：**如果能把图像、声音也切成 token、变成数字向量，那它们不就能进同一个 Transformer 了？** 这就是多模态的全部秘密——**让不同模态共用一套语言：token。**

```
"一只猫"   → 文字token → [t₁, t₂, t₃, …]
🐱 图片    → 图像token → [v₁, v₂, v₃, …]
"喵~" 音频 → 音频token → [a₁, a₂, a₃, …]
→ 全部拼成一串，一起喂给同一个 Transformer
```

一旦它们变成了同一种东西（token），后面的一切——注意力、预测下一个 token、生成——全部照旧。**"预测下一个词"变成了"预测下一个 token"，而这个 token 可能是文字、可能是图像的一块、可能是声音的一帧。**

## 二、图像怎么变成 token？——先看这条最难的路

文字切 token 很容易（按词切），图像怎么切？答案是——**把图切成小块，每块当成一个"词"**。这是多模态最核心的机制：

1. 一张图片先被切成一个个小方块（比如每个 16×16 像素，叫 **patch**，像把一张照片切成拼图块）。
2. 每一块小方块，用一个"视觉编码器"（一个 CNN 或专门的视觉 Transformer，你在《计算机视觉》《卷积神经网络CNN》学过的老朋友）压成一个向量——**每个 patch 一个向量，就像每个词一个向量**。
3. 这些向量**排成一排**，当作"视觉 token"，和文字 token 拼接，一起进大模型。

想想多像你把图切成拼图块，每块标个号，然后让模型"读"这一串号码。**图像就这么变成了 token。** 至于"一块 16×16 的像素变成一个向量"具体怎么压——那正是《卷积神经网络CNN》那篇讲的"小窗口扫图"，现在你知道它在多模态里派什么用场了。

音频同理：声音波形切成一小段一小段，每段压成一个向量，变成"音频 token"。

  > **批注 · 第 1 条（读至"第二节：图像怎么变成 token"处）— 我的理解**
  >
  > 视频可以理解为"按时间排列的很多张图"，但模型读视频不是简单地把每帧都当一张图读：一是帧与帧之间有运动和时间因果（球从左滚到右），只看单帧会丢掉"运动"；二是帧太多算不过来，实际做法是抽关键帧 + 对帧序列做时间建模（把帧当作有时序的 token 串）。多模态也不只是"模型能读文字、图像、音频"，还包括"写"（生成图像/音频/视频），而且精髓在于它们共享同一套 token 表示、能互相转换——看到猫的图能说出"猫"，听到"猫"的声音能画出猫。

## 三、怎么训练？——三种做法

多模态模型怎么做出来的，有三条路线，按"融合的深度"从浅到深：

**路线一：拼接式（最常见的方案）。** 文字模型是现成的（你读过的那些大模型），再加一个"视觉编码器"负责把图变成 token，中间用一个小"投影层"对接。**文字模型本体不动，相当于给一个会写字的专家配了一副"看图"的眼睛。** 训练时先训视觉部分（让它学会把图变成有用的 token），再整体微调。GPT-4V、Gemini 早期走这条。

**路线二：统一 token 化。** 文字、图像、声音全都切成 token，用**同一个** tokenizer（分词器）和同一个模型端到端训练，不分"文字模型 + 视觉编码器"。更强，但训练更重。

**路线三：原生多模态。** 从零开始就用图像、文字、音频混合训练，模型从一开始就"看"着世界学——这是 2024 年后各家追求的方向（GPT-4o、Gemini 的下一代）。

不管哪条路，**最终的效果都一样：一个模型，输入可以混着文字、图片、声音，输出也可以是其中任何一种。**

## 四、它现在能干什么

一张表看清现在的多模态能力：

- **看图说话（Image Captioning）**：发一张图，让它描述——这是最基础的。
- **看图问答（VQA，Visual Question Answering）**：发一张 X 光片问"哪里有问题"，发一张发票问"总金额多少"。
- **图表理解**：把 PDF、表格、图表扔给它，让它总结——办公场景的大杀器。
- **文生图（Text-to-Image）**：反过来，文字 → 图片。注意：这个通常不是多模态 LLM 干的，而是扩散模型（《计算机视觉》那篇提过）。但 2025 年后两者开始融合（一个模型既会看也会画）。
- **语音对话**：你说一句它听一句、答一句，还能感知你的语气（GPT-4o 那种"像真人一样对话"）。

## 五、为什么这是大趋势：多模态 = 更强的"世界模型"

还记得《LLM 的能力与边界》里最重要的边界吗？——**纯文本 LLM 没有世界模型**：它从没"看"过世界，对世界的理解全来自"文字里别人怎么描述"。这句话是纯文本模型的死穴。

而多模态正在补这块拼图：**当模型真的"看过"几百万张照片、"听过"几百万段声音，它对"杯子摔地上会碎"的理解，就不再只是"文字说会碎"，而是"照片里杯子确实碎了"。** 视觉给了模型"世界长什么样"的第一手信息——这正是通向《人工智能》里"世界模型"那条路的一步。

**总结判断**：多模态大模型的全部秘密，一句话——**把图像、声音切成 token，让它们和文字共用同一个 Transformer、同一个"预测下一个 token"的机制。** 它让大模型从"只读文字的书呆子"变成"看过世界的通才"，也补上了纯文本模型最缺的那块地基——对物理世界的直接感知。
