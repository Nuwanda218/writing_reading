你在《大语言模型》演化史里见过 GPT 家族的足迹（第七、八、九步），在《Transformer》里学会了它的心脏。但还有一个完整的故事没串起来：**一个大模型，是怎么从一堆"什么都不会的随机旋钮"，变成你面前那个会聊天的 ChatGPT 的？**

这篇把三件事讲清楚：**预训练**（怎么学会语言）、**解码**（怎么一个词一个词吐出来）、**对齐**（怎么从"续写机器"变成"听话的助手"）。它们合起来，就是一次完整的"炼丹"。

## 一、预训练：让模型"读遍全网，学会语言"

第一步，也是花费最重的一步，叫**预训练（Pretraining）**。目标只有一个：让模型学会**预测下一个词**这件基本功。

**数据从哪来？** 互联网。网页、书籍、论文、代码……随便什么文本。GPT-3 的训练数据，几乎是当时整个互联网的文本，折算成几万亿个 **token**（token 就是模型的基本单位，你在《大语言模型》"一次调用"那节见过）。

**怎么学？** 回忆《机器学习》第五步的自监督学习——**完形填空式地猜下一个词**：给模型"今天天气很____"，模型猜"好"，标准答案就藏在原文里，猜错了就用反向传播调一次参（《神经网络基础》的"猜—错—调"循环）。互联网上有无穷无尽的下半句，模型就这么无限地自学。

### 训练到底怎么跑：先看穿"训练"这件事

讲了"用什么数据学、怎么学"，但你可能还缺几个"训练"的基础概念——它们正是你读 MoE、蒸馏、省显存时需要的钥匙。五个概念，一次钉牢：

**概念一：一次"训练步骤"（Step）= 前向 + 反向 + 更新。** 你已懂"猜—错—调"循环，训练术语把它拆成三步：前向传播（算出预测）、反向传播（算出每个参数该往哪调）、参数更新（梯度下降微调一小步）。跑完这三步，参数被调了一次。

**概念二：数据不是一次全喂，是一批一批喂。** 训练数据几万亿 token，一次学不完、内存也装不下，所以要**切成小块、一批一批喂**——这一批叫 **batch（批次）**。每喂一个 batch 跑一个训练步骤。几万亿 token ÷ 每批的大小 = 总步骤数（GPT-3 大约几十万步）。

**概念三：训练时，显存里装的不只是模型，是四样东西。** 这是"为什么训练那么吃卡"的根本原因：

1. **模型参数**（几百上千亿个旋钮）；
2. **梯度**（每个参数对应一个"该往哪调"的数，和参数一样大）；
3. **优化器状态**（优化器为了"调得聪明"要额外记历史，Adam 优化器常要存参数的 2~3 倍）；
4. **中间激活值**（前向每层算完要留着，给反向传播用）。

四样加起来，**一个 700 亿参数模型训练时的显存需求，是它"参数体积"的十几倍**——这就是为什么 1750 亿的 GPT-3 要上万张卡，也解释了"省显存"为什么那么值钱（你省的就是这四样里的空间）。

**概念四：参数量 vs 激活量（MoE 的钥匙）。** "模型多大"要分成两个数：

- **参数量**：所有旋钮的总数 = 它的**容量**（知识存了多少）。
- **激活量**：这次实际参与计算的参数 = 它的**算力消耗**（每次干活花多少钱）。

普通模型里两者相等；**MoE 让两者分离**——总参数 6710 亿（容量大），每次只激活 370 亿（算力省）。所以读"DeepSeek-V3 总参数 6710 亿、激活 370 亿"时：**6710 亿是知识储量，370 亿是它干活实际花的钱。**

**概念五：训练 vs 推理，天壤之别。**

- **训练**：改参数，要存梯度、优化器状态、中间激活 → 又大又慢，要集群。
- **推理**（你平时调用的）：不改参数，只前向一次 → 轻得多，单卡甚至手机能跑（配量化）。

这五个概念，正好解释了"训练成本上百万美元"的所有疑问——也把 MoE、蒸馏、省显存那几招的地基打好了。

**代价多大？** 这一阶段要用成千上万张 GPU 跑几个月（回收《ImageNet与GPU》的三件套：算法 + 数据 + 算力）。GPT-3 单次训练成本约上百万美元。这是它贵的第一层原因。

**学完的产物是什么？** 一台完美的"续写机器"——你给它前半句，它能顺着编出像模像样的后半句。但注意：**它还不会"回答"**。你问它"1+1=？"，它不会停下来算，而是把问题当上文，自顾自往下编故事。预训练只管"像人话"，不管"答问题"。

**小总结**：预训练 = 用全网文本 + 猜下一个词 + 海量算力，训练出一台"续写机器"。

## 二、解码：一个词一个词地"吐"出来

这台续写机器怎么工作？你在《大语言模型》"一次调用"那节已经看过完整循环：**预测下一个词 → 追加回去 → 再预测 → 循环**，直到吐完。这篇补三个内部机关：

**机关一：采样（Sampling）——不能总选概率最高的。** 模型每次算出"每个词是下一个"的概率分布，但如果永远选最高的那个，输出会机械、爱重复（每句都一个调）。所以它**按概率随机抽**——概率高的更常被选中，但偶尔也抽冷门的，这让回答更自然、更多样。那个"随机性多大"的旋钮就是你在《大模型应用》见过的 **temperature**：调低→稳定机械，调高→天马行空。另一个常用技巧叫 **top-p（核采样）**：先把概率排序，只从"加起来占 90%"的那批词里抽，把特别冷门的词直接排除。

**机关二：束搜索（Beam Search）——保留多条候选一起长。** 翻译、摘要这类任务讲究"整体最优"，而不是"每步最爽"。所以做这些任务时不只留一条路径，而是**同时保留前 k 条候选**（比如 4 条），让它们一起往后长，最后挑整体概率最高的一条。直观说：采样像"赌一把就走一条路"，束搜索像"同时试几条路，最后选最通顺的"。生成型任务（聊天、创作）常用采样；受约束任务（翻译、摘要）常用束搜索。

**机关三：停止条件。** 模型会吐出一个特殊的"结束标记"，或者达到长度上限——这时候循环停止，一段回答完成。

**为什么慢？** 因为每吐一个词，都要把"全部历史 + 已吐的"从头重算一遍（《大语言模型》"一次调用"那节的真相）。你看到的流畅回答，其实是几百上千次"预测下一个词"循环，一次一个词。这里埋个钩子：后面《推理工程》讲的 KV 缓存，就是专门偷这个懒的。

**小总结**：解码 = 采样（按概率随机抽词）+ 束搜索（多条候选选最优）+ 循环，一个词一个词吐出来。

## 三、对齐：从"续写机器"到"听话的助手"

预训练模型会续写，但不会"听话"。要让 ChatGPT 真的回答你的问题，还得做**对齐（Alignment）**——让模型的行为符合人类期待。这一步分两个阶段：

**阶段一：指令微调（Instruction Tuning）。** 人工写几万条"问题 → 好答案"的样本，再训练模型，教它"被问了就要回答，而不是接着编"。学完，模型终于会"一问一答"了。但还有个问题：**它答得不"好"**——可能冗长、敷衍、甚至冒犯。

**阶段二：RLHF（Reinforcement Learning from Human Feedback，基于人类反馈的强化学习）**——这是《强化学习》那篇的实战。完整流程三小步：

1. **收集人类偏好**：让人对同一个问题的多个回答**排序打分**（哪个好、哪个坏）。
2. **训练"奖励模型"**：用这些打分，训练一个小模型学会"预测人类会给这个回答打几分"——它就是"人类口味预测器"。
3. **用强化学习调大模型**：让大模型生成回答，奖励模型打分，然后按强化学习（具体算法叫 **PPO**）让模型往"得分更高"的方向调——做得越好越奖励，跟训宠物一模一样（《强化学习》那篇的核心骨架）。

RLHF 做完，模型从"会回答"变成"回答得讨人喜欢、守规矩"。**今天你跟大模型聊天的那种"舒服感"，大半来自这个阶段。**

（补充一个 2024 年后的新趋势：在数学、代码这类有**标准答案**的任务上，不再需要人类打分，直接用"对不对"当奖励——这叫**可验证奖励（RLVR）**，省掉了昂贵的人工标注。）

**小总结**：对齐 = 指令微调（学会回答）+ RLHF（学会讨喜），一步一个台阶。

  > **旁注 · 第 1 问（读至"三、对齐"处）— 参数训练与 RLHF**
  >
  > **我的疑问**：GPT 训练过程中，这些参数怎么在学习、调整？最核心的内容实际上就是 Transformer 吗？强化学习反馈（RLHF）的内容也进参数之中、影响输出内容了吗？
  >
  > **回答**：
  >
  > **第一问：参数怎么被训练。** 就是反复跑《神经网络基础》第六步那个"猜—错—调"循环，几百万次：前向传播预测 → 算损失 → 反向传播（把错误倒着传回每一层，算出每个参数该往哪边调）→ 梯度下降（所有参数朝损失下降方向微调一小步）→ 换下一批样本再来。几万亿样本 × 几百万步，参数从"随机开始"被慢慢拧成"预测得越来越准"。**训练的本质 = 把随机旋钮拧成准确的旋钮。**
  >
  > **第二问：核心是 Transformer 吗？** 一半对，要补成"三件套"——Transformer 是骨架（参数怎么组织），反向传播 + 梯度下降是拧法（参数怎么调整），数据是教材（教它拧向哪）。参数本身，就是住在 Transformer 结构里的权重矩阵（W_Q/W_K/W_V、前馈权重、嵌入表）。**Transformer 定结构，反向传播定拧法，数据定方向，缺一不可。**
  >
  > **第三问：RLHF 进参数了吗？** 进了，但改的是"表现"不是"知识"。三阶段往参数里写的东西完全不同：预训练写"知道什么"（语言规律、事实知识）；指令微调写"会不会回答"（对话习惯）；RLHF 写"怎么表现"（回答讨喜、守规矩）。类比：知识在入职培训就定了，RLHF 是"情商培训"——知识没变，表达方式变了。所以准确说：**"说什么"来自预训练，"怎么说"来自对齐。**

## 四、一条完整的"炼丹"流水线

把三个阶段串起来，就是一个大模型从无到有的全部：

```
预训练（读遍全网，学会语言）→ 指令微调（学会问答）→ RLHF（学会讨喜）→ ChatGPT
```

三个阶段的**数据量对比**，藏着整个行业的秘密：

| 阶段 | 数据 | 成本量级 |
|---|---|---|
| 预训练 | 几万亿 token（全网文本，自动获取） | 最贵：上百万美元一次 |
| 指令微调 | 几万条（人工写的问答） | 中等 |
| RLHF | 几万条（人工排序打分） | 中等 |

**越往后，数据越精贵、人类参与越重。** 预训练的数据是免费的互联网，但指令微调和 RLHF 的数据每一份都有人工参与——这是"对齐"这个阶段最贵的隐形账单。

**总结判断**：GPT 不是"一个模型"，而是"三个阶段的产品"——**预训练给它语言能力，解码给它生成能力，对齐给它助人能力。** 你之前学的所有零件（Transformer、词嵌入、梯度下降、强化学习）在这里全部汇合。ChatGPT 的火爆，不是哪个单点突破，而是这条流水线每一步都成熟了。
