# 概率图模型：让机器在"不确定"里做判断

> 变更日志：
> - v1.0 | 2026-08-27 11:18:51 | 初版：贝叶斯定理与基础概率谬误、贝叶斯网络图+条件概率表、双向推理手算、朴素贝叶斯

在《专家系统》那篇，你见过一个叫"置信度"的东西——每条规则配一个可信系数，比如"0.7"。当时只提了一笔。但你有没有想过：**凭什么信 0.7？0.7 和 0.8 差在哪？几条规则拼在一起，置信度怎么合算？** 专家系统在这件事上是糊弄过去的，所以它建不成严密的体系。

这篇要讲的，就是把这个"糊弄"变成一门严肃科学的东西——**概率图模型（Probabilistic Graphical Model，PGM）**。它是 AI 对"不确定性"的母语：天气说明天 70% 会下雨，医生说根据这些症状 80% 是流感，垃圾邮件过滤器说这封 95% 是垃圾——**真实世界没有"确定答案"，只有概率。这篇讲机器怎么在概率里做判断。**

## 一、是什么：从"确定"到"概率"，只动了一个字

先看专家系统的规则长什么样：

> "如果发烧且咳嗽，那么是肺炎。"

这是**确定**的——一条规则斩钉截铁。可真实世界是这样吗？发烧加咳嗽，可能是流感（60%）、可能是肺炎（20%）、可能是普通感冒（15%）、还有 5% 别的。**现实从不说"一定"，只说"大概"。**

所以 AI 处理不确定性的第一步，只是把"如果…那么…"里那个"一定"换成一个概率：

> "如果发烧且咳嗽，那么 60% 是流感，20% 是肺炎……"

要表达"60%"这种说法，先得引入一个数学工具：**条件概率（Conditional Probability）**。写法是 P(A|B)，读作"在 B 已发生的条件下，A 发生的概率"。比如：

- P(带伞 | 下雨) —— 知道下雨后，带伞的概率。很高。
- P(下雨 | 乌云) —— 看到乌云后，下雨的概率。也高。
- **注意：P(带伞|下雨) 和 P(下雨|带伞) 不是一回事！** 一个问"下雨时你带伞吗"，一个问"你带伞时天在下雨吗"。这个区别，正是整篇文章的钥匙，下一节会引爆它。

从"规则"到"概率"，好像只动了一个字。但立刻撞上一个新问题：**概率表会"爆炸"。** 假设你要完整描述 20 个变量（发烧、咳嗽、头痛、乏力……），每个变量只有"是/否"两种取值，那"所有情况同时发生"的组合就有 2²⁰ ≈ 100 万个——你要记 100 万个概率。变量一多，直接爆表。

怎么压缩？答案藏在"概率"和"图"这两个词的组合里：**先用一张图画出"谁直接依赖谁"，把一张 100 万的超大表，拆成一堆小表。** 这就是"概率图模型"名字的来历——**概率（怎么量化不确定）× 图（怎么压缩组合爆炸）。**

## 二、怎么来的：AI 向"不确定性"的三次低头

AI 处理不确定性的历史，是一部"三次认输"的历史：

**第一次（1960 年代）：纯逻辑的傲慢。** 早期的符号主义相信，能用确定的逻辑（如果…那么…）推理世界。结果撞墙：现实充满了"大概""可能"，逻辑只会对确定的事实说话。

**第二次（1970—1980 年代）：打补丁的置信度。** 专家系统承认了不确定性，用"置信度 0.7"打补丁。但它是**拍脑袋的**——0.7 怎么来的？多条规则怎么合算？没有数学保证。MYCIN（诊断血液感染的专家系统）用了一套启发式规则合算置信度，在专业领域很好用，但严格说它不严谨。

**第三次（1980—1990 年代）：贝叶斯网络，把不确定性当成一等公民。** 朱迪亚·珀尔（Judea Pearl）提出**贝叶斯网络**，第一次用完整的概率论刻画"谁影响谁、影响多大"。这才是对不确定性的"郑重其事"。珀尔因此拿了 2011 年图灵奖。**这场认输的终点是：不确定性不是 bug，是特性——用概率老老实实建模，比打补丁可靠得多。**

**1990 年代—2000 年代**：朴素贝叶斯横扫垃圾邮件过滤——你每天收到的最有用的 AI 之一。**2010 年代至今**：深度学习抢了风头，但图模型没死——它在"小数据、要可解释、要因果"的场合依然不可替代。

## 三、为什么重要：诊断、天气、垃圾邮件，全是贝叶斯

举三个你天天见、却不知道背后是概率推理的例子：

- **医生**：病人说"我发烧、咳嗽"，医生心里在猜"是流感还是肺炎"。发烧咳嗽是**症状（证据）**，流感肺炎是**病因（要判断的对象）**。医生从证据反推病因——这就是概率推理（下一节的贝叶斯定理），只不过医生用直觉算，机器用公式算。
- **垃圾邮件过滤**：邮箱怎么知道"免费中奖"是垃圾？它按概率判断——历史上含"免费"和"中奖"的邮件，95% 是垃圾。这正是朴素贝叶斯。
- **语音识别 / 机器翻译**：你学的 NLP 里，"哪句话更可能是用户想说的"也是概率判断，背后的隐马尔可夫模型（Hidden Markov Model，HMM）是概率图模型家族的一员。

一句话：**真实世界只有概率，没有确定。** 机器要在这个世界里做判断，就不能只会说"一定对"，得学会"大概对、错多少"。概率图模型，就是这套"大概"的科学。

## 四、树干：一张图 + 一张表，完成全部推理

这一节全程手算，只用小学算术。我们从最震撼的一个例子出发。

### 4.1 贝叶斯定理：怎么"从结果倒推原因"

**先看一个著名案例（癌症筛查）。** 已知：

- 某种癌症的患病率是 1%（100 人里 1 人得病）。
- 检测的敏感度 90%：真得了病的人，90% 会被检出阳性。
- 检测的特异度 95%：没得病的人，95% 检出阴性（也就是 5% 的人没病却检出阳性，叫**假阳性**）。

现在你去做检查，结果**阳性**。问：你有多大概率真的得了癌症？

直觉会告诉你：90% 吧？**错了。** 我们用手算拆开（拿 10000 个人当标本）：

```
10000 人
├─ 100 人真的得病（1%）→ 90 人检出阳性（90% 敏感度）
└─ 9900 人没得病
     └─ 其中 5% 检出阳性 = 495 人（假阳性！）

阳性总人数 = 90 + 495 = 585
阳性里真得病的 = 90 / 585 ≈ 15.4%
```

**检查阳性，真得病的概率只有约 15%，不是 90%！** 为什么直觉错得这么离谱？因为"没得病"的人基数太大（9900 人），他们里面那 5% 的假阳性（495 人）把"真阳性"（90 人）给淹没了。这个坑有名有姓，叫**基础概率谬误（Base Rate Fallacy）**——研究显示，连很多医生都会答错。

现在把上面的计算抽象成公式，它就是**贝叶斯定理（Bayes' Theorem）**：

```
P(病因 | 症状) = P(症状 | 病因) × P(病因) ÷ P(症状)
```

对应到例子里：

| 项 | 含义 | 数值 |
|---|---|---|
| P(病因) | **先验概率**（Prior）：没做检查前，你估计得病的概率 | 1% |
| P(症状\|病因) | **似然**（Likelihood）：真得病了，检出阳性的概率 | 90% |
| P(症状) | 所有人里阳性的总概率 | 585/10000 = 5.85% |
| P(病因\|症状) | **后验概率**（Posterior）：查出阳性后，重新估计的得病概率 | ≈ 15.4% |

**一句话：先验 × 新证据 = 后验。** 这就是贝叶斯推理的全部灵魂——**先有一个初始估计（先验），来了一条证据，把它更新成一个更准的估计（后验）。** 而且妙在后验可以接着当下一次的"先验"，又来一条证据又更新——**证据越多，估计越准。** 你已经学过"从数据里学规律"（机器学习），这其实就是学习的一种原生形态：不断用证据修正信念。

### 4.2 贝叶斯网络：把"组合爆炸"拆成"小表"

单个变量能用贝叶斯定理，但真实诊断有几十个变量互相影响（发烧、咳嗽、头痛、乏力……）。怎么表示"谁影响谁"？——**贝叶斯网络（Bayesian Network，BN）**：**一张有向图 + 每个节点一张条件概率表。**

**有向图**：节点 = 变量，箭头 = "直接影响"。**注意箭头只连"直接"影响**——感冒会直接导致发烧和咳嗽，但发烧和咳嗽之间没有箭头（它俩不互相导致，只是同一根因的两种结果）。这个"只连直接依赖"的规则，就是图能压缩爆炸的命根子：

```
        感冒
       /    \
     ↓       ↓
   发烧     咳嗽
```

**条件概率表（Conditional Probability Table，CPT）**：每个节点配一张小表，记录"在自己的直接原因的各种取值下，自己各取值的概率"。三个节点、三张小表：

```
P(感冒=是) = 0.2          ← 20% 的人得了感冒

| 感冒 | P(发烧=是) |
|:---:|:---:|
| 是   | 0.8         |     ← 得了感冒，80% 发烧
| 否   | 0.1         |     ← 没得感冒，10% 也发烧

| 感冒 | P(咳嗽=是) |
|:---:|:---:|
| 是   | 0.7         |
| 否   | 0.2         |
```

**图的意义：省掉组合爆炸。** 3 个变量的联合分布本来要 2³ = 8 个数字；拆成图之后，只要 1 + 2 + 2 = 5 个数字。变量一多差距爆炸式拉大——20 个变量全联合要 2²⁰ ≈ 100 万个数字，而一张稀疏的图只要几十个小表。**"用图表示结构" = 把天文数字般的概率表，压缩成一套小表。** 这就是"概率图模型"这个家族名字的全部由来：**概率 × 图。**

### 4.3 推理：给定证据，算出后验（完整手算一次）

现在上演最关键的一幕：**已知"发烧了"，推断"是不是感冒"。** 这就是从"症状"反推"病因"——贝叶斯网络的正经用途。

要算 P(感冒=是 | 发烧=是)。套贝叶斯定理：

```
P(感冒|发烧) = P(发烧|感冒) × P(感冒) ÷ P(发烧)
```

逐项代入：

- P(感冒=是) = 0.2
- P(发烧=是 | 感冒=是) = 0.8
- P(发烧=是) = P(发烧|感冒)×P(感冒) + P(发烧|不感冒)×P(不感冒)
  = 0.8 × 0.2 + 0.1 × 0.8 = 0.16 + 0.08 = **0.24**

所以：

```
P(感冒|发烧) = 0.8 × 0.2 ÷ 0.24 = 0.16 ÷ 0.24 ≈ 0.667
```

翻译成人话：**"发烧"这条证据，把"感冒"的概率从先验的 20% 拉高到了 67%。** 医生看到病人发烧，脑子里做的大致就是这个计算。

再补一条证据：又知道病人"咳嗽了"。要算 P(感冒 | 发烧, 咳嗽)。当给出足够证据时，用"分子对比"更快——先算两种可能的"未归一"分数，再归一化：

```
P(感冒 | 发烧,咳嗽)   ∝ P(感冒) × P(发烧|感冒) × P(咳嗽|感冒)
                      = 0.2 × 0.8 × 0.7 = 0.112

P(不感冒 | 发烧,咳嗽) ∝ P(不感冒) × P(发烧|不感冒) × P(咳嗽|不感冒)
                      = 0.8 × 0.1 × 0.2 = 0.016

归一化：0.112 ÷ (0.112 + 0.016) = 0.112 ÷ 0.128 ≈ 0.875
```

**两条证据（发烧 + 咳嗽）把概率推到了 87.5%——证据越多，越确定。** 而且注意一个美妙的性质：这个网络可以**双向推理**——

- **正向（预测）**：已知得了感冒，推"发烧"的概率——顺着箭头走。
- **反向（诊断）**：已知发烧，推"是不是感冒"——逆着箭头走。

规则系统只能朝一个方向推，贝叶斯网络两个方向都通——因为概率本身可逆（贝叶斯定理就是那把"反向的钥匙"）。**一个模型，既能做诊断（症状→病因），又能做预测（病因→症状），这是它比专家系统规则强的地方。**

### 4.4 朴素贝叶斯：图被简化的"糙但有用"兄弟

贝叶斯网络要仔细维护依赖关系，挺贵。现实里有个"偷懒版"，叫**朴素贝叶斯（Naive Bayes）**：**假设所有特征互相独立**——图里一个箭头都不画，各特征的似然直接乘起来。

垃圾邮件例子。判断一封同时含"免费"和"中奖"的邮件是否垃圾：

```
P(垃圾 | 免费, 中奖) ∝ P(垃圾) × P(免费|垃圾) × P(中奖|垃圾)
```

"朴素"就朴素在**假装"免费"和"中奖"完全无关**——其实有关（骗子总两个一起用）。但这个粗暴假设让计算简化到极致，而实战效果出奇地好。**垃圾邮件过滤器——每天帮你拦截垃圾邮件的那位——背后的主力就是朴素贝叶斯。** 它是"用简洁换实用"的教科书案例。

## 五、现在怎么样：它今天活在哪

- **垃圾邮件过滤**：朴素贝叶斯，全球邮箱的后防线。
- **医疗与故障诊断**：从症状推疾病的决策支持、飞机发动机/电网/手机故障排查——"给你一个异常，问你最可能是哪坏了"，正是贝叶斯网络的强项。
- **风险与信用评估**：银行、保险用概率建模违约与理赔风险。
- **语音识别、机器翻译**：隐马尔可夫模型（HMM），NLP 的地基之一。
- **贝叶斯深度学习**：给深度网络也装上"不确定性估计"——让模型能说"我不知道"。这和《LLM 的能力与边界》里的"边界"是同一个方向的努力。
- **与 LLM 的关系**：大模型给的是"最像的回答"，贝叶斯图模型给的是"带概率、可解释的判断"。一个求顺，一个求准。

## 六、将去哪里：从"相关"到"因果"

珀尔后来把贝叶斯思想推向更深处，提出了著名的**因果之梯**（Ladder of Causation）三层：

- 第一层：**相关性**——看到 X 和 Y 总是一起出现。
- 第二层：**干预**——如果我主动把 X 改掉，Y 会跟着变吗？
- 第三层：**反事实**——如果我当初没这么做，现在会怎样？

贝叶斯网络擅长第一层（相关），而"干预"和"反事实"要爬更高两层——那是**因果推断（Causal Inference）**的地盘。这也是 AI 的下一个战场，正好接上你学的《世界模型》：**世界模型要回答"如果…会怎样"，这是因果，不是相关。** 贝叶斯网络，就是这条路上最早的脚手架。

**总结判断**：概率图模型是 AI 处理"不确定"的母语——**专家系统想说"世界一定是这样"，它承认"世界大概是怎样、概率多少"。** 一张图压缩了组合爆炸，一张表记录了影响强度，贝叶斯定理给了它从"结果"倒推"原因"的钥匙。它没有深度学习的光环，却是医疗、诊断、垃圾邮件里沉默的支柱，更是通向"因果"的必经之路。
