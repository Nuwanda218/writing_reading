# 写作阅读仓库（writing_reading）

> 这是我的模型写作本仓库：用 Git 提交历史记录阅读与写作进度，监督自己的成长节奏。

## 仓库定位

- 本地根目录：`F:\书籍\模型写作本`
- 远程仓库：`git@github.com:Nuwanda218/writing_reading.git`
- 仓库只收录写作内容（Markdown 文章），不收录电子书等原始阅读材料

## 目录体系

金字塔四层树状结构，文件夹 = 树枝，文件 = 叶子：

- `_目录.md` —— 文库总索引，新增文章后同步更新
- `_写作规范.md` —— 领域科普写作规范（写作母版）
- `计算机科学.md` —— 森林总图（根）
- `01_理论\` —— 金字塔地基（计算机理论）
- `02_硬件\` —— 硬件层
- `03_软件\` —— 软件层
- `04_应用\` —— 应用层，含人工智能子树（机器学习、强化学习、自然语言处理等，其余分支待写）

每篇文章标题下带版本行：`> 版本 vX.X | YYYY-MM-DD | 变更摘要`。

## 日常使用：按阅读进度推送

每次读完一部分、写完一篇文章或追加旁注后，执行三步：

```bash
git add .
git commit -m "本次内容的说明"
git push
```

## 提交信息规范（中文）

建议格式 `主题: 一句话说明`，例如：

```
人工智能: 新增计算机视觉总览初稿
机器学习: 追加旁注 3 则，v1.2 → v1.3
目录: 登记自然语言处理子叶
```

这样 GitHub 的提交历史就是一条清晰的阅读进度时间线。

## 如何查看进度

GitHub 仓库主页 → 提交历史（Commits）和贡献图，可以直观看到每个阶段的阅读与写作记录。
